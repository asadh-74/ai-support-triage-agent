# App and Website Troubleshooting

## App crashes or will not open
Update the ShopNova app to the latest version from the App Store or Google Play. Then restart the phone and reopen the app. If it still crashes, uninstall and reinstall the app. Order history is stored in the account, so nothing is lost.

## Checkout errors
If checkout shows a payment error, confirm the billing address matches the card statement, then try another browser or the app. Disable ad blockers on the checkout page. Ask the customer for the exact error message and a screenshot if the problem continues.

## Promo codes
Only one promo code can be used per order. Codes cannot be combined with sale items marked final sale. A code that says expired cannot be extended by support.
